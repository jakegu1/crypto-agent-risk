MCP Crypto Agent Risk 代币风险情报

给 AI 代理的「买前安全检查」

在 AI 替你决策之前，先确认这币能不能碰。
MCP over HTTP 多链: ETH / Solana / Base 免费公开 API 实时数据

Crypto Agent Risk 是一个给 AI 代理和开发者使用的代币风险评估工具。它聚合多链流动性、Honeypot 检测、Rug 检查、池子新鲜度，输出一个可执行的判断（low/medium/high）和给代理的一句话建议——而不是让你去解读一堆数字。

🔌 接入（远程 MCP，无需安装）

通过 MCP over HTTP 远程连接，只需一个 URL：

https://124.222.120.49/cryptorisk/mcp

Claude Desktop / Claude Code 配置：

{
  "mcpServers": {
    "crypto-agent-risk": {
      "type": "http",
      "url": "https://124.222.120.49/cryptorisk/mcp"
    }
  }
}

任意 MCP 客户端（Cursor / opencode / 自定义 agent）同样支持。

🧰 工具

assess_token_risk(address, chain_hint?)

核心：聚合多链流动性/合约安全/新鲜度，返回结构化风险画像 + 给 agent 的建议。

{
  "address": "0x7D1A...",
  "risk_level": "low",
  "risk_score": 0,
  "signals": [
    {"severity": "ok", "name": "流动性充足"},
    {"severity": "ok", "name": "多链流通"},
    {"severity": "ok", "name": "非 Honeypot"}
  ],
  "recommendation": "低风险：流动性充足且无 honeypot/高税信号，可正常评估。",
  "confidence": "medium"
}

get_token_liquidity(address)

流动性快照：主交易对流动性、价格、24h 量、跨链数。

find_new_hot_pools(chain, limit)

扫描某链最新创建/最热的新交易池，用于发现新币 + 评估风险。

⚠️ 诚实边界

本工具是情报辅助，不构成投资建议。数据来自公开链上/交易所数据。Honeypot 检测仅覆盖 EVM；流动性数据来自 DexScreener/GeckoTerminal，非真实资金规模。请结合自身判断与尽调。
