## 0. 一句话本质（彻底想清楚它是什么）

**Crypto Agent Risk 是一个「AI 代理的买前安全检查」——一个给想用 AI 做加密决策的人、团队、代理的"防坑门卫"。**

它赚的是**卖铲子的钱**，不是挖矿的钱。它不帮任何人"选币致富"，它帮人"在 AI 替你决策时，先确认这币能不能碰"。

这个定位决定了三件事：
1. **它天然是 B2B / 开发者向**（agent 是它的客户，不是炒币散户——虽然散户是最终受益者）
2. **它的价值 = 信任**（一个做风险检查的工具，一次误判就毁掉信任）
3. **它不是被动收入**（见 §5，这是关键认知）

| # | 客户 | 他们是谁 | 为什么需要我们 | 付费意愿 |
|---|---|---|---|---|
| 1 | **AI 加密 agent / 交易机器人** | 用 Claude/Cursor/自定义 agent 做加密决策的人；加密初创的 agent 系统 | 他们决策快但容易踩 rug，需要一重自动化安全检查 | 中高（API 按量/订阅） |
| 2 | **加密开发者 / 初创** | 做 DeFi、meme、钱包、行情工具的团队 | 需要 risk/intel 数据补充自己产品 | 高（订阅/企业） |

**核心洞察**：客户 1 和 2 是**真正的付费方**。客户 3 是**流量和口碑**来源。客户 4 是**天花板**（能到企业级）。

## 2. 怎么用（它解决什么具体问题）

**当前 3 个工具**（都已上线可用）：
- `assess_token_risk(address)` → 返回一个**可执行的判断**（low/medium/high + recommendation）——这是核心
- `get_token_liquidity(address)` → 流动性快照（判断深度）
- `find_new_hot_pools(chain)` → 扫新池（发现 + 评估新币）

**典型使用场景**（给 agent 的提示词）：
```
"在我建仓 0xABC... 之前，先 assess_token_risk 评估它，如果 high 就跳过。"
"扫一下 Solana 最新的 5 个新池，列出哪些有 rug 风险的。"
"查一下这个币的流动性深度，判断滑点风险。"
```

**一句话**：它把"我要不要碰这个币"这个主观问题，变成一个 agent 能**自动决策**的判断题。

## 3. 护城河（诚实分析 —— 这是你最关心、也最容易误判的点）

**直接说结论：产品层面的护城河很浅，护城河在别处。**

### 为什么产品没有深护城河
- 数据源是**公开免费的**（DexScreener/GeckoTerminal/honeypot.is/CoinGecko/RugCheck）——竞品也能拿到
- 代码逻辑（信号加权 + 组合规则）**可被克隆**——你的对手也能写一个
- 这个赛道**没有专利**、没有独家数据、没有网络效应

### 真正的护城河在哪（这是我作为负责人要带你建的东西）

调研结果直接点破了：**"In a small niche, distribution IS the moat. Product moats are weak at micro-SaaS scale because features are easy to clone. Brand, niche authority, and switching inertia are the real protections."** [3]

所以护城河 = **三样东西的叠加**：

| 护城河 | 怎么建 | 难度 |
|---|---|---|
| **① 分发/信任（最重要）** | 在 MCP 生态 + 加密开发者社区建立**"这个工具靠谱"的名声**；被主流 agent 收录 | 你擅长（SEO/GEO/内容/社区） |
| **② 细分权威** | 在"代币风险/防rug"这个小垂直里成为**公认的名字**（像 Nomad List 之于远程办公） | 需要持续内容 + 口碑 |
| **③ 数据加工能力（半优势）** | 你的风险评分是**聚合+判断**，不是简单转售——这个"加工的准不准"是累积信任，别人短期抄不走 | 持续改进 |

**我的判断（负责）**：你造的不是一个有技术护城河的产品，是**一个靠"信任 + 分发"建立壁垒的 SaaS**。这**完全可行**（Bannerbear 单人到 $25K+ MRR 就是靠细分+信任），但它**需要运营**，不是"做完就不管"。

## 4. 它是被动收入型，还是需要持续运营？（重要认知）

**坦白说：它是一个"半被动、低维护、但必须运营"的产品。**

| 维度 | 现实情况 |
|---|---|
| **代码维护** | 低（数据源是第三方的，我们只做聚合+评分；除非 API 变了，否则几乎不用改代码）。重启周期可能一个月一次 |
| **数据源稳定性** | 中（3个免费源，任一挂了结果变差；需要偶尔检查）。监控是低成本的 |
| **增长/获客** | **需要持续做**（这才是"运营"的主体）——不推广，它就永远默默无闻 |
| **信任维护** | 关键（每次误判都是风险），需要持续校准评分逻辑 + 接受反馈 |

**结论**：它不是"躺赚"型（像买了个收租资产那样）。它是"**建好基建后，主要成本是获客和信任维护**"的类型。**代码成本降到近乎零，但增长成本是持续的**——这正是你相对其他"做完就跑"项目的优势，因为**你能持续做内容/分发**。

**如果你想做成被动收入**，唯一路径是：**把基建做稳 + 让它进主流 MCP 目录 + 建一个能自我引流的内容飞轮**，然后靠生态自然增长。但即使那样，早期也需要你投入。

## 5. 怎么运营 / 维持 / 更新（具体计划）

我把它分成**三条线**，分别对应"产品、增长、信任"：

### A. 产品线（低频，维护为主）
- **监控**：定时检查数据源健康（少量 cron job）
- **校准**：收到用户反馈后，调风险评分阈值/组合规则
- **高价值迭代**（不频繁，但每次值得）：
  - 加 `confidence` 字段（已做）
  - 加更多信号（持有集中度、持仓画像、解锁事件 → 接回我最早调研的 token unlock 缺口）
  - 可选：加"历史表现"（这个工具过去有没有漏判/误判）

### B. 增长线（高频，这是运营主体）
按优先级排序：
1. **进 MCP 目录**（Glama 最优先——自动索引 GitHub repo；官方 Registry 其次）——**一次投入，长期被发现**
2. **小而准的落地页**（能被 AI 引擎读到 + 被开发者找到）——不是大 SEO 站
3. **内容分发**（你的核心优势）：
   - 用 Ahrefs 验证的低竞争高CPC词（`whale alert` 难度10、`rug pull checker` CPC$400、`meme coin tracker` 难度9）写**权威指南 + 内置工具**
   - 在加密/开发者社区（X/GitHub/Reddit）分享"如何用 agent 防 rug"的内容
4. **接入真实 agent 生态**：让它能被主流框架（如 ElizaOS 等）按插件/MCP 收录——这是最大的增长杠杆

### C. 信任线（持续，负责人最看重）
- **诚实边界**：永远标注"不构成投资建议"、`confidence` 字段、数据来源
- **宁可误杀不漏杀**（防 rug 工具，漏掉 rug 是致命的）
- **监控误判**：确保不会把 safe 币标成 high 的误判过多

## 8. 更聪明的办法 / 思维方式（负责人视角的建议）

我作为负责人，给你几个**可能比逐条执行更聪明**的思维框架：

### 🟢 观点1：把"护城河"从"工具"搬到"信任与分发" —— 别再纠结工具本身
你已经在纠结"它没有技术护城河"了。**这个纠结是浪费**。微 SaaS 的护城河从来不在代码，在**信任 + 分发**。你的优势恰好在后者（懂 AI/开发/SEO/GEO/分发）。**把精力从"再写个更聪明的评分算法"转到"让更多人相信并看到它"。**

### 🟢 观点2：做一个"内容 + 工具"的飞轮，而不是孤立工具
最强的微 SaaS 是**"工具引流 + 内容建立权威"**。你写"如何判断一个币是不是 rug"的权威内容（SEO/GEO），读者用了你的工具 → 产生信任 → 传播。**这是你区别于纯代码型对手的真正壁垒**（他们能抄代码，但很难抄一个持续的权威内容库）。

### 🟢 观点3：别一开始就贪"通用" —— 在一个窄点上打出名声
`assess_token_risk` 是通用的，但**对"防 rug / 扫新币"这个具体场景**市场最疼、CPC 最高（$400）、你在 r/solana 也看到有用户分析了56.7万 meme 币（群体级痛点）。**先在这个窄点做成"公认的防 rug 工具"，再扩展**。这比泛泛的"代币风险"更容易出名。

### 🟢 观点4：把"接入主流 agent 生态"当成最高优先级的单次动作
一个 MCP 产品，**被主流 agent 框架/目录收录**（如 ElizaOS 插件、官方 Registry、Glama）是**一劳永逸的"分发"**——比你自己 SEO 半年有效。**这应该是你接下来最值钱的一个动作**（就是我上一轮说的①落地页+②Glama）。

### 🔴 观点5（负责人必须说的）：别指望它让你"靠币致富"
这是对你最重要的一条。**我们做的是工具钱、信任钱，不是行情钱。** 如果你哪天想让我用它来"推荐买什么币"，那就是跑偏了，我会提醒你。它能给你的，是一个**稳定、可持续、可积累**的现金流和品牌，不是暴富。

## 10. 风险与红线（负责人本分）

1. **信任即产品**：做风险检查的工具，一次误判毁信任。**我倾向宁可误杀不漏杀**。
2. **数据源依赖**：3个免费源，任一挂了结果变差。用 `confidence` 标注 + 备多余源。
3. **行业波动**：加密高监管高波动，政策一变压断数据链。备源 + 关注政策。
4. **别跑偏成"炒币工具"**（最重要求，见观点5）。
